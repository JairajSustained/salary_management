## Goal
Build a minimal yet usable salary management tool for an organization with 10,000 employees.

## Requirements
### Managing Employees -
- Add, View, update, and delete employees via UI
- The employee must have a full name, job title, country, salary, along with any other meaningful data that you believe should be captured
- Users will have roles (HR, Manager, Employee) and will be able to perform actions based on their roles
- Users should be able to register using email address, password
- Users should be able to login using email address

### Salary Insights via UI -
- Minimum, maximum, average salary of employees in a country
- Average salary for the given Job Title in a country.
- Any other meaningful metrics you believe are helpful for the user persona.

### Seeding
- Seed script with 10,000 employees. Full names should be generated by combining values from first_names.txt and last_names.txt
- Create a management command that takes data from first_names.txt and last_names.txt
