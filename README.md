# Salary Management Tool

A minimal salary management tool for HR Managers to manage 
employees and view salary insights across countries and job titles.

## Tech Stack
- Backend: Python, Django, Django REST Framework
- Frontend: ReactJS
- Database: PostgreSQL
- Deployment: Railway (backend), Vercel (frontend)

## Features
- Employee CRUD (Add, View, Update, Deactivate)
- Salary Insights (Min, Max, Average by country and job title)
- Bulk import of 10,000 employees via seed script
